# UI/UX Wireframes & Theme

## User Journey

1.  **Authentication**: Faculty members log in using their email and password.
2.  **Dashboard/Class Selection**: Upon login, faculty see an overview of their classes and key metrics. They select a specific classroom to manage.
3.  **Attendance Marking**: Faculty mark attendance for the current session (Morning/Afternoon). The system provides a simple toggle for present/absent.
4.  **Student Management**: Facultly can add students, view their attendance history, and see their ML-generated risk level.
5.  **ML Insights**: Faculty can view class-wide analytics, including heatmaps of attendance patterns and identified trends (e.g., student consistency scores).

## Color Palette & Theme

The application uses a **Modern Dark Theme** with high-contrast accent colors for data visualization.

*   **Background**: Deep Indigo/Coal (`#0f172a`)
*   **Surface (Cards)**: Glassmorphism Slate (`rgba(30, 41, 59, 0.7)`)
*   **Primary Accent**: Electric Blue (`#3b82f6`)
*   **Success (Present)**: Emerald Green (`#10b981`)
*   **Warning (Risk)**: Amber/Orange (`#f59e0b`)
*   **Danger (Absent)**: Rose Red (`#f43f5e`)
